🎮 Tetris Game
A classic Tetris game built with pure HTML, CSS, and JavaScript.

📌 Key Points

Single file project — only tetris.html needed
No frameworks, no dependencies, no installation required
Works in any modern browser
Mobile friendly with touch and swipe support
High score saved in browser (localStorage)


🚀 How to Run

Download tetris.html
Double-click to open in your browser
Click START GAME or press Enter to play


🕹️ Controls

← → — Move left / right
↑ or Z — Rotate piece
↓ — Soft drop
Space — Hard drop (instant)
P — Pause / Resume
Enter — Start / Restart


🏆 Scoring

1 Line → 100 × Level
2 Lines → 300 × Level
3 Lines → 500 × Level
4 Lines (Tetris!) → 800 × Level
Soft drop → +1 per row
Hard drop → +2 per row


🟦 Pieces

I — Cyan straight line
O — Yellow square
T — Purple T-shape
S — Green S-shape
Z — Red Z-shape
J — Blue J-shape
L — Orange L-shape


✨ Features

All 7 classic Tetris pieces
Ghost piece (landing preview)
Next piece preview panel
Score, Level, Lines counter
High score saved across sessions
Speed increases every 10 lines
Pause and resume support
Neon retro visual style
Mobile on-screen buttons + swipe gestures


💡 Tips

Use the ghost piece to aim before dropping
Check the Next panel to plan ahead
Clear 4 lines at once for maximum points (Tetris!)
Keep the board flat to avoid gaps
Use hard drop at higher speeds to stay in control

Go to Settings → Pages

Visit your GitHub Pages link to play online
